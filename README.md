# 双子守护者 · 发布准备版 v0.10

原创双人合作塔防，使用 Godot 4.7.2 / GDScript。包含十关战役、六位奇幻 Q 版英雄、四种基础塔、八条三级路线、十六种最终分支、塔旁操作菜单、主动技能接力与关卡事件。

## 启动

从 GitHub 下载源码后，需要安装 Godot 4.7.2，并导入 `game/project.godot`，在编辑器中运行主场景。仓库不包含 `.tools` 开发运行时或 `builds` 游戏包。使用本机现有环境时可直接运行下面的启动器；正式游戏包需要把 EXE 与同名 PCK 放在同一文件夹。

双击根目录 Play.cmd，或 builds/TwinGuardians/Play.cmd。点击旗帜选关，分别选择 P1 / P2 英雄，再点击「出征」。默认公平挑战统一双方等级；也可选择保留旧档的成长战役。本机练习按 Tab 切换玩家。左上角邀请面板支持创建房间、复制房间码、输入 IP:端口和搜索附近房间；默认 UDP 24820、发现端口 24821，双方需要同一构建。支持可直连网络，尚无公网中继。

## v0.10 发布准备

- 前三关逐步教学，后续机关按状态解释；支持关闭教学。
- 选中塔按 1 / 2 放技能，C 选择技能就绪的塔，全部支持改键。
- 低、中、高特效设置，危险预警始终保留；塔技能与危险提示使用不同音效。
- 本地试玩反馈导出、可选自动记录、联机诊断与首次连接超时提示。
- 有效存档备份与损坏恢复；正式 Windows x86_64 导出、应用图标与 SHA256 清单。

说明见 [v0.10 更新](docs/16-v10-release-preparation.md)，验证见 [v0.10 测试](docs/validation/v10-tests.md)，真人与双机验证见 [发布清单](docs/17-playtest-and-release-checklist.md)。

## v0.9 策略深度与合作

高级塔现已加入分支配色、动态光环、弹道拖尾和技能释放特效，见 [高级塔特效](docs/15-advanced-tower-effects.md)。

- 三级路线选定后，每种最终塔可购买两项主动技能，各有两级；购买、施放和冷却均在塔旁菜单中，详细说明仍按需展开。
- 荆棘边境增加道路切换，月影渡口增加英雄护送，寒晶堡垒增加地基封锁与付费解封。
- 新增拆塔者、分裂怪与独立裂隙领主；领主具有双人破印、阶段召援和可躲避的范围预警。
- 塔主可授权队友操作，队友用自己的金币升级和学习技能；撤销立即生效，出售仍由塔主决定。

完整说明见 [v0.9 更新](docs/14-v09-strategy-expansion.md)，验证见 [v0.9 验证](docs/validation/v09-tests.md)。

## v0.8 通关星级与自动返回

- 通关按水晶扣血评星：0–2点三星、3–10点二星、11–19点一星，通关至少一星。
- 显示评价与三秒倒计时，随后自动返回主界面；失败不授星、不自动返回。
- 关卡地图与详情显示历史最高星数，低分重打不会覆盖高分。
- 成长战役与公平挑战均保存星数，兼容旧英雄存档；双方联机可靠同步结算。

完整说明与截图见 [v0.8 更新](docs/13-v08-stars-and-results.md)，验证结果见 [v0.8 验证](docs/validation/v08-tests.md)。

## v0.7 基础塔与三级分支

- 空地固定建造弓箭塔、兵营、法师塔、火炮塔，依次升至二级、三级。
- 三级完工后才解锁两条塔型路线，每条路线包含两种能力分支；弩炮、雷塔、灯塔和炼金塔不再能直接建造。
- 分支实际转换造型与功能，选择后固定；菜单显示额外费用，出售包含全部投资。
- 塔旁操作与折叠说明保留，悬停分支预览实际射程。

完整说明与截图见 [v0.7 更新](docs/12-v07-tower-progression.md)，验证结果见 [v0.7 验证](docs/validation/v07-tests.md)。

## v0.6 英雄与关卡

- 选关改为两行五列，保留塔旁菜单、八种塔及十六项专精。

## v0.5 玩法与操作

- 点击地基或塔，在旁边建造、升级专精、切换索敌、设置集结点与确认出售；详细说明按需展开，悬停建造选项预览射程。
- 新增鹰眼弩炮塔、连锁雷塔、守护灯塔；八种塔各有两个三级专精。
- 六英雄增加协作/突击两种本局专精；队友技能留下四秒弱点，可主动接力爆发。
- 六关各有独立预警事件，双英雄分守信标可提前化解；新增护盾卫士与战地祭医。
- 弱化普通伤害数字，显示队友状态和固定共鸣响应按钮；复盘提示具体漏怪的应对办法。
- TG 房间码与60秒自动重连；分流、喷火及援助放入可展开的战术工具。

完整说明与截图见 [v0.5 更新](docs/10-v05-strategy-and-controls.md)，测试结果见 [v0.5 验证](docs/validation/v05-tests.md)。

## 操作与开发

Q 施法，U 强化，R 团队共鸣，右键 / WASD 移动，Space 准备，F 救援，Tab 本机换人，G 在鼠标位置标记补位。按键可在设置中修改。详细说明见 [原型说明](docs/07-playable-prototype.md)，验证见 [游戏验证](docs/validation/game-tests.md)。

```powershell
./tools/run-godot.ps1 -Editor
./tools/test-game.ps1
./tools/build-game.ps1
```

当前验证结果见 v0.10 验证记录。两台物理电脑、macOS、公网、低端设备和真人平衡尚未实测。便携包已使用官方 Godot release 模板正式导出。

源码入口 game/scripts/main.gd；规则 game/scripts/core/；网络 game/scripts/network/；画面 game/scripts/ui/；数值 game/data/。技能与被动配置为 data/heroes.json，成长公式为 core/hero_rules.gd，存档为 core/career.gd。
