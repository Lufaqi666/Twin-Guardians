# 编码前准备结论

## 项目假设

按一名主要开发者组织工作，Codex 承担设计细化、实现与可自动执行的检查。用户不必先准备正式美术。实际开发人数和可投入时间尚未知，因此采用按验收推进的阶段计划，不承诺日历日期。真人试玩与第二台设备测试仍须实际安排，不能用模拟结果代替。

## 目标和边界

核心假设是：交叉区让两人的火力接力，跨玩家冰碎让配合产生清晰收益。原型要验证这两个假设。单局目标 20 至 25 分钟暂为产品目标，不作为当前十波配置已经达成的事实。

### 第一轮闭环 V0

1 张灰盒地图、前 3 波、3 种攻击塔、双人选择节点与建造、共享水晶、普通／重装／刺客、冰碎、金币和结算。首先单机双席位调试，随后接入真正双进程联机；V0 不能只交付单机演示。英雄、油污、兵营、机关和共鸣不进入最初闭环。

### 原型 V1

V0 通过后加入第 4 至 10 波、兵营与炼金塔、2 英雄、空军／精英／首领、机关、大招、转账、教学和重连。完整原型共 5 塔、2 英雄、6 类敌人。先用占位素材，再谈正式美术。

### 暂缓

公网匹配、云存档、局外属性成长、单人 AI 队友、隐形、分支进化、商店和房主迁移。macOS 导出在 Windows 原型可靠后处理。保留扩展数据结构，不预先实现这些系统。

## 已落地的选择

英雄用 WASD／右键移动；塔攻击自动索敌。节点建造不要求英雄靠近。移动、救援、技能施法需检查距离。双方可选所有塔与同一英雄；地图职责固定 P1／P2，大厅交换侧别会连同玩家席位一起交换，不只移动英雄。

共享节点按 Host 验证成功顺序占用，失败不扣款。闸门要队友确认，喷火可单独启用。连锁必须跨玩家触发，普通赏金均分。冻结采用减速标记，而非硬停；硬停仅由共鸣大招提供。

原型不允许加入已开始的陌生对局，仅允许原席位重连。观察、重播与开放房间匹配均后置。

## 项目准备完成条件

- 路线、节点和火力覆盖可按坐标复现，分流无环。
- 配置存在单一数值来源，版本号可参与连接校验。
- 前 3 波有可复现推演并明确模型限制。
- 任务有依赖、交付物和通过条件。
- 界面反馈覆盖正常、失败、待确认和断线状态。

上述准备已落实。T00 的便携编辑器下载、版本冻结、空项目导入及无窗口启动已通过；尚未验证有窗口 GPU 渲染、导出与真机联机，分别在首图呈现、打包和 T07 阶段执行。下一项工作为 T01 配置加载器。
