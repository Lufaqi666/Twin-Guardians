## 坐标与资源

逻辑格点采用连续浮点数，x 向右、y 向下，路径距离按折线欧氏长度。最终等距显示可用 screen_x = (x − y) × 32、screen_y = (x + y) × 16；起始窗口 1280 × 720，保持逻辑射程与缩放无关。建塔节点使用稳定 ID，不能用数组位置作身份。

## 场景规划

`Main → Lobby / Match / Result`。Match 包含 MapView、UnitView、Effects、HUD。逻辑 MatchState 不持有纹理、音效或 UI 节点；呈现层消费状态与事件。模拟步 20 Hz，绘制每帧进行；Client 对快照插值，不推进敌人、伤害、金币或波次。

|模块|责任|禁止承担|
|---|---|---|
|ConfigCatalog|校验 JSON、建立 ID 索引、计算内容哈希|直接改 UI|
|MatchState|单位、节点、金币、波次、状态、胜负|调用网络 API|
|CombatResolver|命中、抗性、连锁、状态归属、死亡|由客户端决定赏金|
|WaveDirector|消费出怪事件、清场与准备阶段|自行增加难度系数|
|CommandProcessor|权限、条件、去重与原子交易|先扣金币再尝试占节点|
|NetworkSession|席位绑定、RPC、发现、快照、重连|把任意消息直接执行为脚本|
|Presentation|地图、动画、音效、面板、提示|修改权威 HP 与余额|

## 网络约定

游戏 UDP 端口 24820，房间发现 UDP 24821。同一对局最多 2 玩家。ENet channel 0 放可靠命令／确认，channel 1 放不可靠有序快照，channel 2 放重连基线等可靠大消息；避免大基线阻塞操作确认。自动发现失败时仍可手动连接，不自动配置路由器或防火墙。

握手字段为 protocol_version、config_hash、player_token、room_id。首连由 Host 分配席位；重连验证原令牌。命令只传 type、command_id、sequence、payload，player_id 来自连接绑定，客户端不得自报成另一人。

命令 ID 按会话唯一；Host 缓存本局结果，重复请求返回原结果。快照包含 match_id、epoch、tick、单位及塔状态、节点管理者、金币与余数、HP、波次、机关、共鸣、倒计时。重连获取完整基线及 last_processed_sequence 后再开始消费增量，忽略旧 epoch 包。

3 秒无心跳视为疑似断线并暂停模拟；暂停后 60 秒重连窗口使用单调墙钟。普通玩法计时使用模拟时间，不能用已经暂停的模拟时间计算重连期限。Host 离开则结束对局，不迁移房主。

## 时间和结算

每步处理命令事务 → 出怪与移动 → 攻击命中 → 状态及持续伤害 → 死亡与赏金 → 漏怪扣血 → 胜负与阶段。命中先于漏怪；HP 归零优先于清场胜利。状态在命中时按到期时刻校验，t >= expire_at 视为过期。

币值用 1/4 金币整数记账，例如 B×50% = 2B 个单位，B×75% = 3B 个单位；显示整金币，余数保留，支出只能整金币。避免二进制浮点造成奖励误差。生命取 nearest half up，与 Python 默认 bankers rounding 区分。

标记默认暴击率为 0，只对跨玩家直接攻击增加 50 个百分点。若跨玩家火炮命中冰霜，该主目标攻击被冰碎替代，忽略暴击、光环和兵营增伤；其他目标仍按普通范围伤害处理。主目标排除在冰碎碎裂溅射之外，其他目标同次命中可承受普通炮击与碎裂各一次。

炮弹原型飞行速度 8 格／秒；射出时固定落点，命中时在落点计算目标与状态。模拟推演目前使用即时命中，因此炮弹与刺客之间的命中关系是实机验证重点。
