# 可玩原型 v0.3（历史版本）

当前版本为 v0.4，关卡、挑战模式、设置及合作反馈变更见 [v0.4 说明](08-v04-improvements.md)。以下记录 v0.3 原始规则。

## 启动与关卡

Windows 双击根目录 Play.cmd。便携版在 builds/TwinGuardians/，复制整个目录后运行其中 Play.cmd。源码修改后运行 tools/build-game.ps1 重新打包。

大厅点击战役旗帜，选择 P1 / P2 英雄，预览固定技能和被动。创建房间后选择锁定，取消房间可以重新选择。三关全部开放，各自加载道路、塔基和出兵配置。

|---|---|---|
| 交汇庭院 | 森林交叉防线 | 10 / 206 |
| 霜脊隘口 | 雪地弯道，装甲提前出现 | 10 / 206 |
| 余烬遗迹 | 沙漠长廊，最终双巨像 | 10 / 207 |

## 一个固定技能与被动

每位英雄只有一个 Q 主动技能；按钮自动瞄准附近敌人，键盘 Q 使用鼠标位置。R 是双方共同确认的团队共鸣。下列伤害为一级英雄、一阶技能基础值，实际伤害受抗性影响。

| 英雄 | Q 固定技能 | 伤害 / 冷却 | 被动 / 阻挡 |
|---|---|---|---|
| 霜卫统领 | 凛冬裁决：自身周围冰爆、减速、治疗 | 150 魔法 / 16 秒 | 每三击冰霜，支援队友塔 / 1 |
| 炎刃游侠 | 烈焰破阵：突进、范围伤害、眩晕、点燃 | 190 魔法 / 14 秒 | 吸血，每三击追加真实伤害 / 2 |
| 磐石骑士 | 撼地审判：震地、击退眩晕、治疗、护佑 | 180 魔法 / 18 秒 | 减伤，三级反击 / 3 |
| 逐风猎手 | 鹰隼箭雨：范围对地对空、标记 | 180 物理 / 14 秒 | 每三击双倍伤害 / 1 |
| 余烬法师 | 陨星焚城：范围爆发、五秒火区、点燃 | 240 魔法 / 20 秒 | 普攻留下火焰残留 / 1 |
| 雷霆祭司 | 天罚雷暴：最多六目标、眩晕 | 220 魔法 / 16 秒 | 每三击连锁两个附近敌人 / 1 |

雷暴后续目标按 90% 递减。巨像眩晕上限 0.5 秒，不能被震地击退。震地和突进不对空。指定施法位置限制七格，突进三格。技能蓄力 0.18–0.45 秒，倒地取消蓄力，冷却保留。

## 成长与强化

英雄等级 1–8，累计经验门槛为 0、80、200、360、560、800、1080、1400。每次击杀向双方英雄各发一次经验：步兵 6、重甲 12、刺客 8、飞行 8、精英 20、巨像 80。倒地也获得经验，升级不会立即复活。

每级生命提高基础值的 12%，普攻提高基础值的 10%。二级和四级各获得一个技能点，按 U 或点击强化使用，最高三阶，不花金币。每阶增加基础技能伤害的 35%、范围的 8%，冷却减少基础值的 8%；英雄等级额外每级提高技能伤害的 8%。例如四级、二阶法师的陨星基础伤害约 402。

六级强化被动：统领冰霜延长、游侠吸血提高、骑士减伤 40% 且多一个阻挡位、猎手普攻标记、法师火区扩大、祭司连锁三个目标并延长眩晕。骑士三级获得 30% 减伤、20% 原始受击量的真实反击；五级可以阻挡巨像，巨像占三个阻挡位。

停驻在地面敌人一格内即可阻挡，兵营士兵优先。移动和倒地释放敌人，飞行敌人绕过。敌人周期性反击；脱战六秒后每秒回复最大生命的 1.2%。倒地十二秒复活，可由队友提前救援。

## 存档

每个席位、每个英雄独立保存经验和技能阶数，换关、重开和重新启动保留。本机练习保存双方，联机保存自己的席位。每秒、退出和断线时写入临时文件后替换存档，旧对局不能回退已有成长。

存档为 Godot 用户目录的 hero_progress_v1.json，一般位于 `%APPDATA%/Godot/app_userdata/Twin Guardians/`。预览与自动测试不写正式存档。旧版随机技能不再使用。

## 操作

| 操作 | 效果 |
|---|---|
| 左键塔基 | 选择，右栏建造、升级、出售 |
| 右键地图 / WASD | 移动当前英雄 |
| Q / 技能按钮 | 唯一英雄技能，鼠标指定 / 自动瞄准 |
| U / 强化按钮 | 使用技能强化点 |
| R | 申请共鸣，队友三秒内确认 |
| 按住 F | 靠近倒地队友救援 |
| Space | 确认下一波，本机练习确认双方 |
| Tab | 本机练习换人 |
| Y / N | 同意 / 拒绝分流请求 |
| Esc | 取消选择 |

公共塔先到先建，私有塔仅所属玩家可建。升级暂停攻击两秒，出售二次确认并返还累计投入 70%。练习另一英雄自动普攻与阻挡，需要换人后手动施法。

## 邀请与联机

左上角面板支持创建、复制地址、输入 IP、搜索附近房间。房主决定关卡，加入者选择 P2 英雄，成长档案交由房主用于本局。相同构建，防火墙允许 UDP 24820，发现使用 24821。

掉线暂停，原客户端六十秒内原地址重连，保留英雄、成长、技能及冷却。房主退出结束会话。支持同一局域网，不包含互联网匹配或 NAT 穿透。

## 战斗反馈与边界

箭矢、法球与炮弹飞行后命中，近战挥击与敌人反击有动作。受击闪白、轻微反冲、血条拖尾、分类伤害数字及数字避让帮助辨认命中。蓄力、范围预警、陨星轨迹、冰刺、雷柱、箭雨、冲击环、轻微震屏、短暂视觉停顿、死亡残影、升级光效和分层合成音效补充反馈。视觉停顿不暂停联机模拟。

五种塔三级外观使用原创程序矢量，参考卡通奇幻塔防的清晰轮廓与立体感。无背景音乐或配音。战斗画面预览设置成长与敌人排列并标注为预览，不能作为通关证据。

194 项检查、本机双进程联机和三关真实经济通关已验证。两台物理电脑、真实丢包、macOS、长期多局和真人平衡尚未验证。便携包为开发运行时。教程、改键、音量设置、手绘动画、兵营自选集结点和更多地图待迭代。
