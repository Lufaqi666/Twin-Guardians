# 双子守护者 v0.4

战役从三关扩充到六关，各十波，保留六英雄、五类塔、局域网合作及原有成长档案。

## 六关战役

| 关卡 | 推荐英雄等级 | 侧重 |
|---|---|---|
| 交汇庭院 | 1 | 入门，中央元素接力 |
| 霜脊隘口 | 2 | 重甲与防空 |
| 余烬遗迹 | 3 | 精英及最终双巨像 |
| 荆棘边境 | 4 | 短交汇区，刺客交替压线，侧翼阻挡 |
| 风暴哨站 | 5 | 第二波开始空袭，空军绕开中央，侧翼防空 |
| 裂隙要塞 | 6 | 长交汇区，重甲和精英，第八波起连续巨像 |

所有关卡直接可选。新增三关各有独立道路、地基和波次文件；没有增加敌人种类。推荐等级是引导建议，不是进入限制。

## 成长与公平挑战

大厅关卡详情下选择模式。成长战役继续使用旧经验和技能阶数，并按原规则保存成长。公平挑战将双方英雄统一为四级、三阶技能，全局不获得经验，也不写英雄成长存档。加入者遵循房主选择，换英雄和重连仍保持统一等级。挑战模式重开仍使用相同起点。

原有成长伤害公式保留。这次用独立挑战模式提供可比较的合作起点，没有清空或削减旧存档。大厅英雄预览随模式切换显示实际出战等级。

## 情报、教学和合作

- 备战时从真实出兵配置生成下一波敌人数量、A/B 入口分布和对空、重甲、刺客、巨像的应对提示。备战地图上以蓝色虚线提示空军路线。
- 底部前三波分阶段说明建塔、英雄阻挡与救援、跨玩家碎冰和共鸣。设置中可关闭，或仅跳过本局。
- 指挥台的防空、补位、集火按钮进入地图标记模式，再点击战场发送。默认 G 在鼠标位置发送补位标记。每位玩家只保留一个标记，持续六秒，发送间隔两秒；联机由房主验证并同步。
- 跨玩家碎冰和点燃、共鸣成功、救援、金币援助显示合作消息，短消息同时出现在指挥台和底部反馈区。
- 胜负复盘展示协同击杀、元素连锁、双方连锁参与、救援及援助到账金额；漏怪按波次、敌人类型和出口汇总。连锁参与属于双方共同贡献，不是个人最后一击排名。

## 战场与集结点

英雄使用持续的玩家色轮廓和上层身份文字。倒地英雄突出请求救援；即将到达出口的空军、刺客显示危险标识；巨像蓄力显示冲击范围和倒计时。

伤害数字保留原有同目标短时间合并和避让，同屏最多显示十八个，并可整体关闭。可以关闭震屏及视觉停顿。

选中自己的兵营后点击“设置集结点”，再点击兵营五格内的道路。位置会吸附到道路，士兵逐步行走过去，移动途中释放阻挡。队友不能调整你的集结点，过远或离开道路的指令会被拒绝。Esc 取消当前标记或集结操作。

塔与情报区域支持滚动；英雄操作、机关和准备按钮固定在指挥台下方。

## 设置

大厅和战斗顶部均有设置入口。总音量、震屏、伤害数字、教学及十三个操作按键可保存。选择一个动作后点击改键，再按新键；重复按键交换原有绑定，Esc 保留用于取消。技能、共鸣、确认按钮和教学提示使用更新后的按键名。

设置存在 `user://preferences_v1.json`，与 `hero_progress_v1.json` 分开。关闭设置时保存，测试和战斗预览不写正式偏好。联机打开设置不会暂停战斗，面板会拦截本人地图操作和快捷键。

## 验证边界

自动检查涵盖六关几何、事件顺序、出兵和胜利闭环、固定挑战等级、存档隔离、标记权限及同步、集结范围与行走、救援和援助统计、设置读写与按键交换。经济通关脚本没有直接发钱、强制杀敌或恢复水晶；风暴哨站使用侧翼防空策略，其他关卡使用中央接力和逐步扩建策略。

GPU 截图验证覆盖六旗战役大厅、设置、备战情报和结算复盘。它验证布局，不等同于真人试玩。两台物理电脑、真实网络丢包和真人平衡仍需实测。

测试存档隔离在 `.work/tests/`，引擎日志也显式写入该目录。此环境中的 Godot 会报告无法读取系统证书库，测试脚本仅排除这条精确的系统警告，仍拒绝其他引擎错误、脚本错误及泄漏。
