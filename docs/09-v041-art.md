# v0.4.1 美术质感调整

参考 [Ironhide 官方《王国保卫战》页面](https://www.ironhidegames.com/Games/kingdom-rush) 的卡通奇幻塔防方向，沿用项目自己的矢量建筑、人物和地形系统。

本次更改：

- 森林、雪地、沙漠使用原创噪声笔触材质与边缘暗部，地面纹理生成一次后缓存。
- 土路保留真实模拟中心线，增加路肩、亮边、车辙和碎石；可点击塔基与单位坐标一致。
- 橡树使用不规则树冠、多层明暗和树干；雪松与棕榈补上材质高光。
- 建筑共享石墙裂片、灰缝、屋顶瓦片、分层接地阴影，各级外观仍由原有塔系统绘制。
- 人物增加皮肤阴影、布料折面、腰带和不同敌人的装备轮廓；英雄肖像增加护甲、布褶及面部细节。
- 界面改为有纹理的木框羊皮纸与绿色嵌板按钮；九宫格材质按颜色缓存，进度条单独使用薄样式。
- 战役地图增加海岸描边与地表笔触。所有图片均为实际游戏场景捕获，不是另做的概念图。

这是程序绘制美术的质感升级，仍有明显的几何轮廓；尚未达到完整手绘角色动画和逐关插画背景的精细程度。

验证：UI 16 / 16、改进功能 30 / 30 通过，实际 GPU 渲染检查大厅、战斗、设置、雪地与沙漠。关卡数据和战斗数值不变。便携包已重建。

当前环境仍出现 Godot 系统证书警告；首轮 GPU 运行还曾遇到无法写入沙箱外着色器缓存的警告，重新捕获未出现脚本错误。没有据此宣称全设备性能已验证。
