# 双子守护者 v0.5 · 塔旁操作与合作策略

## 塔旁菜单

点击地图上的地基或防御塔，会在选中位置旁显示浮动菜单。菜单优先放在有空间的一侧，限制在战场区域内，保留选中塔的可见空间；点击空白、× 或 Esc 可以关闭。地图标记和兵营集结点放置时菜单隐藏，以便选择目标。

空地基提供八种塔的图标与价格。悬停选项会预览射程，按钮悬停提示说明用途；点击“详细说明”展开数值与专精说明，说明区域可以滚动。金币不足、升级进行中、队友所有权和暂停状态分别限制相关操作。金币变化只更新按钮状态，不反复重建菜单。英雄移动也不重建固定 HUD。

升级、五种索敌策略、兵营集结点与二次确认出售都在塔旁完成。右侧指挥台保留波次情报、关卡事件、队友状态、固定英雄操作和地图标记；分流、喷火与援助收入可展开的“战术工具”。

## 八种塔与十六项专精

专精在升至三级时选择，费用沿用原三级升级费用，不额外收费。选择后本局不能更换。兼容原规则命令：未指定专精的三级塔仍可使用，随后可免费选择一次专精。

| 塔 | 基础职责 | 两种专精 |
|---|---|---|
| 游侠弓箭塔 | 高频物理，对地对空，标记协作 | 疾风连射：快攻短射程；猎空哨兵：强化防空、削弱对地 |
| 冰霜塔 | 魔法减速，与队友火炮碎冰 | 广域寒潮：范围与持续时间；深寒印记：伤害与碎冰增益 |
| 重型火炮塔 | 地面范围物理，碎冰与点燃 | 破甲重炮：穿甲、小爆炸；碎冰轰击：强化接力、削弱普通炮击 |
| 圣骑士兵营 | 三名士兵阻挡，五格道路集结 | 坚守盾卫：更多生命、较低伤害；机动卫队：快速移动、高伤低血 |
| 炼金塔 | 油区减速与点燃 | 黏稠油沼：范围与减速；烈性燃剂：更强燃烧、更短油区持续 |
| 鹰眼弩炮塔（新增） | 六格长程，可对空，穿透物理抗性 | 远距狙击：高伤远程慢攻；贯甲重弩：更强穿甲、降低基础伤害 |
| 连锁雷塔（新增） | 魔法弹射，最多三目标 | 电弧扩散：五目标、降低首击伤害；过载雷击：高伤、仅两目标 |
| 守护灯塔（新增） | 治疗英雄与士兵，增益队友攻击塔 | 庇护之光：强治疗小范围；接力战旗：队友塔增益更强、治疗减半 |

穿甲按物理抗性百分点扣减，最低为零。灯塔治疗与伤害增益取附近最强来源，不叠加；不能复活倒地英雄。灯塔不会扩大攻击塔射程，霜卫统领原有队友塔射程支援仍生效。塔旁射程预览采用实际专精和统领支援范围。

索敌可循环切换：出口优先、生命最高、飞行优先、速度优先、护甲优先。飞行优先没有可攻击空军时会继续攻击地面。兵营依靠集结点与阻挡选择敌人，灯塔支援盟友，二者不提供无效的索敌切换。

## 主动合作与英雄选择

六英雄保留一个主动技能，新增本局二选一专精。协作专精扩大技能范围25%、降低直接伤害15%，技能同时治疗附近盟友并提供护佑；突击专精提高伤害25%、缩小范围15%，冷却增加10%。备战且技能不在冷却或蓄力时可调整，不写入旧成长存档。

英雄主动技能命中，会在敌人身上留下四秒金色弱点。另一玩家的主动技能在窗口内命中，消耗弱点并追加该次技能基础伤害35%的真实伤害，记录主动接力与双方合作贡献。自动塔连锁继续保留，主动接力是额外的时机选择。

公平挑战成为大厅默认推荐：双方统一四级、三阶技能；成长战役仍可选择并保留旧档。队友生命、倒地救援与技能就绪状态持续显示；共鸣请求到达时，固定按钮变为“响应!”。

## 六关事件与敌人

交汇庭院第3、7波，其他关卡第4、8波开始8秒后出现事件预警。预警持续6秒，事件持续18秒。双英雄各守一个不同信标，持续3秒可化解事件，获得25点共鸣；移动离开或倒地会中断进度。信标允许交换职责，化解奖励不能重复领取。

| 关卡 | 事件及应对 |
|---|---|
| 交汇庭院 | 双子试炼：练习双线驻守，不附加危险效果 |
| 霜脊隘口 | 凛冬雪暴：局部英雄移速降低35%、塔攻速降低25%；转移或化解 |
| 余烬遗迹 | 余烬喷涌：局部英雄与士兵持续受伤；移动、治疗或化解。英雄的环境伤害最低保留1生命 |
| 荆棘边境 | 荆棘封锁：局部英雄移速降低30%，士兵持续受伤；调整集结点 |
| 风暴哨站 | 疾风空袭：飞行敌人暂时加速30%；侧翼防空、飞行优先 |
| 裂隙要塞 | 裂隙增援：生效时双路各增援一个护盾卫士，8秒后再来一组；及时化解可阻止后续增援 |

新增护盾卫士（80护盾）与战地祭医（每3秒治疗附近敌人18生命）。第5波起部分步兵替换为这两类，保留原有出兵时间与基础波次人数。裂隙事件额外出兵计入胜负闭环，全部敌人解决后才能结束本波。

## 辨识度、复盘与联机

普通伤害小于35时不显示数字，较大伤害数字更小、更淡；同屏数字数量收紧并避让英雄、浮动菜单与战场边界。原有数字与震屏设置继续有效。英雄只保留一个上层玩家身份标识；护盾、主动接力弱点、信标进度、事件危险区和倒计时可在地图辨认。

复盘新增主动技能接力、化解事件与使用塔型数量，按实际漏过的敌人类型给出下一局应对建议。

创建房间后可复制 TG 房间码，包含 IPv4 地址与端口；加入支持房间码、IP:端口及 IPv6 地址。断线后客户端在60秒内自动重试，保留原席位、指令序列、英雄专精和塔专精；到期停止自动循环，也可手动重连。切换到不同房主地址时不发送旧房间的席位令牌。

房间码仅简化地址输入，不提供 NAT 穿透或公网中继。互联网免配置连接需要新增中继/平台网络服务；本轮没有部署外部服务。

## 验证

详见 [v0.5 验证记录](validation/v05-tests.md)。验证包含规则、菜单边界、实际技能效果、两种模式的本机双进程联机、自动重连、六关三种开局与两种新阵容的正常经济通关，以及 GPU 界面捕获。

这些是自动化与本机渲染验证，不替代真人双人试玩、两台物理电脑或公网网络测试。优先真人观察连锁理解时间、每局有效搭配、事件是否迫使交流，以及玩家失败后是否能选择新的应对策略。
