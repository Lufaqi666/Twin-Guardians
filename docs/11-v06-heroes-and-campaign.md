# 双子守护者 v0.6 · 奇幻 Q 版英雄与十关战役

## 六位英雄统一重绘

战场角色与头像共享原创程序矢量绘制 `game/scripts/ui/hero_art.gd`，采用大头比例、圆润五官、明暗分面、披风与金属描边。六位英雄有各自的头饰、武器和配色：

| 英雄 | 外观 |
|---|---|
| 霜卫统领 | 冰晶冠、银白发、蓝色铠甲与寒冰权杖 |
| 炎刃游侠 | 火色短发、红色飘带与双刃 |
| 磐石骑士 | 重型头盔、大盾、厚肩甲与战锤 |
| 逐风猎手 | 绿色兜帽、羽饰、精灵耳与长弓 |
| 余烬法师 | 火焰法帽、白发、深红长袍与火焰杖 |
| 雷霆祭司 | 紫色法衣、编发、金色光环与闪电杖 |

战场形象保留移动步态、披风摆动、呼吸与攻击动作；受到伤害时变亮。英雄血条与玩家标识上移，伤害数字避让区域相应扩大。头像和场景使用同一角色造型，避免大厅与实战风格不一致。此次更新不改变英雄成长存档。

## 新增四关

战役从六关扩展至十关，共一百波。新增地图拥有独立道路、塔基布局、空军路线、出兵配置与事件。关卡仍开放直选，推荐等级是成长战役的参考；公平挑战继续统一双方等级。

| 新关卡 | 推荐等级 | 主要变化 |
|---|---|---|
| 月影渡口 | 4 | 双岸分开推进，共享塔基位于两路之间；祭医与护盾配队。月影潮汐暂时加速地面敌人25% |
| 沉沙神殿 | 5 | 较长交汇区、装甲纵队及最终双巨像；流沙区英雄和士兵移速降至60%，塔攻速降至70% |
| 寒晶堡垒 | 6 | 空军提前从外侧绕行；晶盾区每6秒为附近敌人补充40护盾，上限80 |
| 星陨之门 | 7 | 精英、飞行、治疗者交替压线，第8波巨像、最终双巨像；星陨区每5秒伤害英雄与士兵 |

事件沿用6秒预警与双信标化解机制：两位存活英雄分守不同信标3秒，可以提前停止事件并获得25共鸣。星陨环境伤害对英雄最低保留1生命；士兵可被击倒。月影水潭、沉沙神殿、水晶簇与星门符文提供独立地图装饰。

战役选关改为两行五列，十个旗帜和名称均在地图面板内显示。已有塔旁操作菜单、八种塔与十六项专精继续保留。

## 验证与启动

双击根目录 `Play.cmd` 或便携包内 `builds/TwinGuardians/Play.cmd`。所有联机玩家需要使用同一版本。

使用 `tools/test-game.ps1` 验证内容、界面、成长、事件、联机和不同阵容；正常经济通关脚本不额外发金币、强杀敌人或恢复水晶。规则测试中的固定数据夹具不计入经济通关。当前结果见 [v0.6 验证记录](validation/v06-tests.md)。

新造型与新关卡截图来自实际 GPU 运行场景；展示中的单位站位与经济由预览脚本设置，不能作为通关证据。
