# 双子守护者 v0.7 · 基础塔与三级分支

空地固定提供弓箭塔、兵营、法师塔和火炮塔。每种基础塔依次升至二级、三级；三级升级完成后，塔旁菜单才出现分支选择。分支不在二级提前选择，也不能直接建造高级塔。

| 基础塔 | 三级路线一 | 三级路线二 |
|---|---|---|
| 弓箭塔 | 游侠弓箭塔：疾风连射／猎空哨兵 | 鹰眼弩炮塔：远距狙击／贯甲重弩 |
| 兵营 | 圣骑士兵营：坚守盾卫／机动卫队 | 守护灯塔：庇护之光／接力战旗 |
| 法师塔 | 冰霜塔：广域寒潮／深寒印记 | 连锁雷塔：电弧扩散／过载雷击 |
| 火炮塔 | 重型火炮塔：破甲重炮／碎冰轰击 | 炼金塔：黏稠油沼／烈性燃剂 |

共四种基础塔、八条塔型路线、十六种最终分支。菜单按两列显示塔型路线，每列提供两个能力分支；点击一次即可确定塔型与能力。转换会改变实际攻击、射程、伤害类型或支援方式，同时换成对应的塔造型。兵营转灯塔会撤离该塔士兵，提供治疗与队友塔增益。

基础建造费用保持100／110／120／125金币，二、三级升级分别为基础费用的80%／120%。分支选择显示额外费用，计算为目标塔基础费用的三倍减去累计投资，最低为零。弩炮额外150金币、雷塔75金币、灯塔60金币；其余路线已包含在三级升级费用中。没有负费用或转换退款。分支转换需要2秒，期间不能重复升级、改分支或出售。

选择后固定分支，塔仍为三级最高级；需要改变路线时可出售重建。出售按全部累计投资的70%取整返还，包含分支额外费用。选择权限、金币检查、非法塔系拒绝和最终塔型均由主机执行，网络快照和自动重连保留基础塔系、最终塔型与能力分支。英雄成长存档不受影响。

操作继续靠近所选塔，详细说明默认收起。悬停分支预览的是转换后的实际射程，包括该分支的射程系数与队友统领增益。详细说明可滚动阅读；兵营转灯塔的士兵撤离会直接提示。
