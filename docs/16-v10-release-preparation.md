# v0.10 发布准备 · 2026-10-05

本次围绕“让陌生玩家能理解、能操作、能稳定启动”改进。新增行为如下。

## 渐进教学与快捷技能

前三关分别聚焦建造与英雄守线、三级分支与塔技能、接力与双人分工。提示根据是否建塔、是否选择分支、是否学习技能、是否完成接力变化；后续道路切换、护送、封锁在对应状态显示机制说明。没有锁住高级玩法，熟练玩家可在设置中关闭教学。

默认 `1 / 2` 施放选中塔的两项技能，`C` 循环选择已学习、冷却完成、当前可操作的塔。快捷键不会自动购买或绕过冷却、权限、施工与封锁；队友授权后的塔也可以选择。塔旁按钮显示对应键位，全部新按键支持重绑定。旧档的自定义按键优先保留；新增默认键冲突时分配空闲按键。

## 战斗可读性与声音

设置增加低、中、高特效：低档关闭高级塔环境装饰与拖尾，技能保留范围提示；中档保留环境特效但减少技能粒子和攻击脉冲；高档完整显示。Boss、关卡机制的危险预警不受该设置影响。

八种高级塔的主动技能使用不同合成提示音，危险事件有独立警示音。声音保留六个并发声部、事件限流；重要提示可以替换普通命中声，减少密集战斗中提示被淹没的情况。现有音量、伤害数字和震屏设置继续有效。

## 本地试玩反馈

设置里的“试玩反馈 / 导出本局记录”可以填写难度感受和文字意见，保存 JSON 并复制文件路径。记录包含阵容、分支、学习技能、金币采样、漏怪、塔伤害和指令计数。客户端异步请求单独记为 pending，不冒充已被主机确认的操作。

“自动保存本地试玩记录”默认关闭，开启后退出一局时保存。记录仅在本机，不自动上传，不包含连接地址或重连令牌；文字意见由玩家自行输入。自动采样每十秒一次，每局最多六百条，不持续累积无上限日志。存储目录为 Godot 用户数据目录中的 `playtest_reports`。

## 联机与存档

首次加入超过十二秒未完成验证会结束等待，显示版本、UDP、防火墙和直连条件的排查提示，避免大厅一直无法重新选关。原席位重连仍采用六十秒重试流程。设置增加“复制联机诊断”，包含版本、模式、连接状态、重试次数和配置哈希，排除地址和令牌。

有效存档更新前保留上一份备份。主存档损坏时读取备份，下次保存恢复主存档。不能保证备份包含刚完成但未成功保存的进度；两份都损坏时仍无法恢复。

## 正式 Windows 导出

`tools/install-export-template.ps1` 下载官方 4.7.2 模板，使用官方 SHA512 校验后仅提取 Windows x86_64 release 模板。`tools/build-game.ps1` 使用正式导出预设，包含应用图标、版本号、许可和 SHA256 文件清单，不再把编辑器二进制当作游戏运行时。开发测试脚本从发布包排除。为保留现有配置哈希逻辑，规则脚本按文本方式导出。

启动 `builds/TwinGuardians/Play.cmd`；根目录启动器优先启动已有正式包。源码更新后需要重新构建，才能让根目录启动器使用新内容。

导出方案参考 [Godot 官方 Windows 导出文档](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_windows.html)，模板来自 [官方 4.7.2 发布](https://github.com/godotengine/godot-builds/releases/tag/4.7.2-stable)。

本版本仍是发布候选的准备版本。真人平衡、物理双机、跨网络中继、低端设备、长期多局和商店素材审核需要继续验证，见 [试玩与发布清单](17-playtest-and-release-checklist.md)。本次未对未知真人反馈做数值改动，也未上线服务器或发布商店。
