## 复现

```powershell
./tools/test-game.ps1
./tools/build-game.ps1
```

完整测试会执行自动重连与两种新阵容；也可以单独执行 `tools/test-auto-network.ps1` 和 `tools/test-formations.ps1`。日志在 `.work/tests/`，结构化汇总在 [v05-results.json](v05-results.json)。

GPU 捕获脚本是 `game/tests/visual_v05.gd`，通过引擎运行并输出到 `docs/design/`。

## 实测边界

这些结果验证规则闭环、可重复策略、界面布局与本机网络同步，不等同于真人平衡或“最佳阵容”证明。尚未完成真人双人测试、两台物理电脑、真实网络丢包、公网 NAT 穿透、中继或 macOS 验证。没有部署公网服务。

环境仍有 Godot 无法读取系统证书库的精确警告；测试只排除该已知警告，拒绝其他脚本错误、引擎错误和泄漏。
