经济测试只使用正式命令与金币收入；高级塔必须建造基础塔、依次升级并支付转换费用。策略先预留转换投资，再扩建阵容。弩炮和雷塔阵容还断言最终确实使用对应高级路线。正常经济通关不额外发金币、强杀敌人或恢复水晶。
